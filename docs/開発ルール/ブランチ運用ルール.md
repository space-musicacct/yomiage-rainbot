## 2. 目的

本ドキュメントは、本リポジトリにおけるブランチの構成と、`main` ブランチへのマージ手順を定めるものである。

---

## 3. ブランチ構成

`develop` ブランチは設けず、`main` と作業用ブランチで構成する。

| ブランチ               | 用途                                |
| ---------------------- | ----------------------------------- |
| `main`                 | 基本となるブランチ                  |
| `feature/<担当者名>/*` | 作業用ブランチ。`main` から作成する |

例えば、space が担当する作業用ブランチは `feature/space/*` となる。

`fix` や `hotfix` など、上記以外のブランチも必要に応じて使用してよい。命名は `feature` と同様に `<種別>/<担当者名>/*` とする (例: `fix/space/*`、`hotfix/space/*`)。

---

## 4. `main` へのマージ

- `main` へのマージは必ず PR (Pull Request) 経由で行う
- 1 ユーザー以上からレビューを受けてからマージする
