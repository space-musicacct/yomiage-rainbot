## 4. 対象利用者

### 4.1 利用者一覧

| 利用者種別 | 説明 | 主な利用内容 |
| --- | --- | --- |
| 一般利用者 | 対象サーバーのメンバー | 読み上げの開始・終了、メッセージの読み上げ、自分の声・速度・ピッチの設定、サーバー辞書の登録・削除 |
| サーバー管理者 | 対象サーバーで、サーバーの設定を変更する権限を持つメンバー (具体的な権限は 8 章で定める) | サーバー単位の読み上げ設定、メンバーの読み上げミュート、他のメンバーの声の上書き、JSON ファイルによるサーバー辞書の一括登録 (Discord の「管理者」権限を持つメンバーのみ。既存 Bot の辞書の引き継ぎ等に用いる) |
| 運用者 | Bot を運用する担当者 (space) | Bot のホスト、設定ファイル (`server_id.json` 等) の管理、グローバル辞書の管理、ログの確認、障害対応 |

## 5. スコープ

### 5.1 開発対象

| 項目 | 内容 |
| --- | --- |
| 開発対象 | Discord の読み上げ Bot |
| 主な対象 | テキストチャンネルのメッセージと、VC の入退室の読み上げ。利用者ごとの声の設定、辞書、読み上げの管理 |
| 対象サーバー | `server_id.json` に設定したサーバー (複数設定できる) |

### 5.2 対象外

既存 Bot (ずんだもんβ) の機能のうち、本システムで扱わないものは以下のとおり。

| 項目 | 理由 |
| --- | --- |
| キュー連動の速度アップ | リソース消費上の懸念があるため、今回は見送る |
| アラーム | 読み上げ Bot に必ずしも必要な機能ではないため |
| 翻訳 | 読み上げ Bot に必ずしも必要な機能ではないため |
| 韓国語での読み上げ | 読み上げ Bot に必ずしも必要な機能ではないため |
| 本文中の指定 (`.v` / `.p` / `.s`) による声・ピッチ・速度の一時変更 | 読み上げ Bot に必ずしも必要な機能ではないため |
| 緊急地震速報 | 読み上げ Bot の責務の範囲を大幅に超えるため |
| プレミアムプラン (Stripe 連携、`/activate` を含む) | すべての導入サーバーに汎用的に読み上げを提供する用途ではなく、対象サーバーを限定して運用するため |
| シャーディング・クラスタ構成 | すべての導入サーバーに汎用的に読み上げを提供する用途ではなく、対象サーバーを限定して運用するため |
| 管理サーバー限定の運用コマンド (`/stop`、`/restart`、`/reload`) | 運用の操作はサーバーに SSH して行えばよいため。異常があった場合も、ログを確認できなければこれらのコマンドだけでは根本的な解決にならず、利点が少ない |
| GPU サーバーでの合成 | サーバー・開発用のノート PC のいずれも合成に使える GPU を持たず (ノート PC は CPU 内蔵のグラフィックのみ)、検証する手段がないため |
| ステータス表示 (接続数・生成時間) | すべての導入サーバーに汎用的に読み上げを提供する用途ではなく、対象サーバーを限定して運用するため |

## 7. 機能要件

### 7.1 機能一覧

| ID | 機能名 | 概要 | 備考 |
| --- | --- | --- | --- |
| F-001 | 対象サーバーの制限 | `server_id.json` に設定したサーバーでのみ動作する | 設定にないサーバーでの動作は Q-008 |
| F-002 | 読み上げの開始・終了 | コマンドで VC に接続・切断し、読み上げ対象のテキストチャンネルを記録する | |
| F-003 | メッセージの読み上げ | 読み上げ対象のテキストチャンネルの発言を読み上げる。`!` / `！` で始まる発言は読まない | |
| F-004 | 読み上げキュー | サーバーごとに、読み上げを順番に処理する | |
| F-005 | スキップ | 今の読み上げを止める | |
| F-006 | 自動接続 | 登録した VC にメンバーが入ったとき、自動で接続する | |
| F-007 | 自動切断 | VC が Bot だけになったとき、自動で切断する | |
| F-008 | 入退室の読み上げ | Bot が接続中の VC へのメンバーの入退室を読み上げる | |
| F-009 | 名前の読み上げ | 発言者の名前を読み上げる。さん付け、連投時の名前の省略を含む | |
| F-010 | 本文の変換 | URL・絵文字・スポイラー・コードブロック・メンション・添付ファイル・スタンプ・転送メッセージを、読み上げ用に変換・省略する | |
| F-011 | 読み上げ文字数の上限 | 上限を超えた部分を省略する | |
| F-012 | 声・速度・ピッチの設定 | 利用者が自分の声・速度・ピッチを設定する | |
| F-013 | 声の選択 UI | 声の一覧から選んで設定する | |
| F-014 | 他のメンバーの声の上書き | サーバー管理者が、サーバー内でのメンバーの声・速度・ピッチを上書きする | |
| F-015 | サーバー辞書 | サーバーごとの辞書の登録・削除・表示 | |
| F-016 | サーバー辞書の一括登録 | JSON ファイルでサーバー辞書を一括登録する | Discord の「管理者」権限を持つメンバーのみ (4.1) |
| F-017 | 正規表現による辞書 | 辞書の単語を正規表現で指定する | |
| F-018 | 音声辞書 | 単語を、登録した音声ファイルで読み上げる | |
| F-019 | グローバル辞書 | 対象サーバーすべてに適用する辞書 | 運用者が管理する (4.1)。更新の手段は Q-009 |
| F-020 | メンバーの読み上げミュート | 指定したメンバーの発言・入退室を読み上げない | |
| F-021 | 使わせない声の設定 | サーバーで使わせない声を設定する | |
| F-022 | Voice Override Mode (仮称) | 読み上げの途中で、別の利用者の声に切り替わる挙動 | 設計メモ、アンケート回答記録の投稿 3・6・8 |
| F-023 | サーバー単位の読み上げ設定 | 自動接続先、名前の読み上げ、入退室の読み上げなどを、サーバーごとに設定する | 対象の項目は機能詳細で定める |
| F-024 | 再起動からの復帰 | Bot の再起動後に、停止前に接続していた VC へ接続し直す | 状態の保存方法は Q-010 |
